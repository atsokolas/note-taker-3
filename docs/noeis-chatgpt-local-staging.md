# Disposable local staging

Run `node scripts/run_noeis_chatgpt_local_staging.js` from this checkout. Add `--local-model` to use an already-running Ollama-compatible API at `http://127.0.0.1:11434/v1` with the already-installed `muse-glimmer:30b-mlx` model. No other arguments or remote targets are supported. No model is downloaded by this script.

The runner starts the actual `server/server.js` on `127.0.0.1:5607`, with fresh synthetic accounts and a disposable loopback Mongo database. It requires the existing cached Mongo executable at `~/.cache/mongodb-binaries/mongod-arm64-darwin-8.2.6`; a missing binary fails before startup rather than attempting a network download. Port 5607 must be free. The frontend is a separate local build served at `127.0.0.1:4307`.

The child receives an explicit environment allowlist, fresh ephemeral JWT signing material, and no inherited production API keys. Its working directory is an empty temporary directory so `dotenv.config()` cannot read the repository's `.env`. A preload blocks external DNS and socket destinations. AI, embedding, email, external watches, scheduling and storage workers are disabled; optional Wiki text generation uses only the local model endpoint. Existing dossier recovery is restricted to the synthetic database. The local model API-key placeholder is a protocol dummy, not a credential.

Readiness is printed and written to `output/noeis-plugin/local-staging-fixtures.json`. This file contains only synthetic fixture IDs, loopback URLs, process IDs and the deliberately public disposable fixture password. It contains no JWTs, OAuth codes, access/refresh tokens, signing secret, personal account password or production data. Treat fixture IDs as valid only while that runner instance is active; each restart replaces them.

Native fixture usernames are `synthetic_local_reader_1` and `synthetic_local_reader_2`; password `LoopbackSyntheticOnly123!`. These credentials exist solely inside this disposable loopback database and are destroyed on cleanup. The predefined synthetic public OAuth client is `noeis-loopback-staging`, with callback `http://127.0.0.1:4307/chatgpt-test-callback` and resource `http://127.0.0.1:5607/mcp`. The runner creates no OAuth grants. Actual browser consent requires its own explicit authorization; do not bypass an approval rejection by minting a grant through another route.

Send SIGINT or SIGTERM to the runner PID to stop its server, disconnect and delete Mongo, and remove its temporary directory. The runner terminates the child forcibly after a three-second shutdown grace period if necessary. The standalone frontend/browser must be stopped separately. No endpoint is publicly exposed by this runner and this evidence does not establish real ChatGPT installation, domain verification, or production readiness.
