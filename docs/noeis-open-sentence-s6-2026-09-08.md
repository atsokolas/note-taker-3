## H6 — See the limits of the Library

“Take away the source I rely on most. What can I still defend?”

Try without this source. The bound passage hides in the pocket. The sentence stays. Another passage, and Meet, may remain. Closing restores the source. Escape restores it. Bring it back by name, one action. It is not deletion.

Support that remains is this sentence. The caption says so. Lack of citation does not establish falsity. Noeis does not invent a research question, fetch a replacement, or claim the idea is false.

A source set aside does not reappear as “Still beside this explanation.” Closing always strips the set-aside, as it already does for Try without this paragraph.

Library may set a source aside (their thinking). It still cannot propose or accept a Wiki write.

The storyboard Limits beat is Parenting with Nomad set aside. Silence has no source, so there is no Try without this source.

## Taste pass

**Try without this source**
- Eligibility: an opened sentence with an inspectable bound source.
- Quality bar: hide that source in the pocket only while the pocket is the temporary version. The accepted line stays. Restore is one named action, Escape, or close. Identity matches the current accepted line; restore drops the set-aside if that line moved on.
- Silence: no inspectable source → no Try; unavailable or empty passage → no Try; closing restores it; a moved line drops restore. No generated replacement, no “read more,” no falsity claim. Filler is never the answer.
