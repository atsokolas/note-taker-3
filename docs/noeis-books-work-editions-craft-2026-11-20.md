# Keep your place

Books leaves a small ribbon beside the title you came back to. The shelf entry in browser history holds the title’s position and focus. Work signs off a review only after the last decision is acknowledged. Editions puts you back at the finding when you step out to the rest of the issue.

## Regression scenarios

- On a long Books shelf, open a title below the first screen. Return with the Books link and with browser Back. Check that the same title has focus at the same viewport position. If the book disappears while open, return to the shelf heading. Open a book directly in another tab and check that its Books link still reaches the shelf.
- In Work’s weekly review, start with the last item and leave an earlier one undecided. Check that focus wraps to the earlier item after acknowledgement. File the last decision, check the sign-off, and Undo. The sign-off should disappear while a decision remains.
- In Editions, filter a multi-author issue and open the second finding. Return via the issue link or Escape. Check the author filter, keyboard focus, and position beneath the fixed navigation. Reload the bookmarked issue, and confirm that an existing column link still opens its first visible finding.
- Check at 430px with touch and keyboard, at 1320px, and at 1440px. Repeat the narrow layout with larger text and reduced motion.

## Next details to try

- Work could print a brief “Monday starts here” preview on a collapsed review, starting with the first acknowledged carryover and leaving the line out when nothing is planned.
- Editions could let you copy a finding as a small clipping with its headline, issue, and link back to the exact paragraph. The clipping would carry only the editorial text you chose.
