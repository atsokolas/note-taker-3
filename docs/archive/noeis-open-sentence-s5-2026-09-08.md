## H2 — Uncertainty that stays alive

Keep “I cannot tell whether this is patience or inertia” as written. Do not force a conclusion or a task.

The pocket already had an unfinished question. It also had “A note for your return” with a “Next: …” prompt — the same slot used twice, once as a todo. That field is gone. In its place, the person can **name the distinction that would help**. One field. Their words. Empty until they name it.

Then’s recorded question stays under Then. It is not copied into today’s question or into the distinction. A stored `returnNote` restores as a distinction and is not written back.

The way home is quiet: the named distinction, or “You left this open.” if only the question remains. A distinction that repeats the question is not a second way home. No timer, overdue badge, or generated paraphrase.

Later, a third recorded passage may sit beside that distinction. The caption is “Bears on this distinction.” The exact saved words stay. Noeis does not write why, and it does not claim the question is resolved. Leave-open without that passage stays silent. This is relevance-triggered continuity through the existing pocket, not a new return surface.

When Then holds a recorded question, the same distinction field sits beside it as a dated reply. Then’s question stays. The date is stamped once; a lifted note without a date stays undated. No second binder. No worldview-change announcement.

## H4 — Invent an intellectual instrument

The Parenting distinction is already named. Keep it as an instrument under a name the person types. The definition is their distinction at keep time. Apply that named tool beside another sentence — Compute, runway, rollback — without writing the article.

It is not a prompt preset. Noeis does not generate a definition, a name, or a worldview-change announcement. Empty name is not an instrument. Apply is an explicit act; opening another sentence does not attach it.

The held name and definition travel on the device (`noeis.open-sentence.instrument`). Applying rebinds `against` to this line. Name and definition stay. A different live distinction on that line is not overwritten. Leave the instrument on this sentence; the held tool remains for another line. Clearing the name unmakes it.

Library may keep and apply (their thinking). It still cannot propose or accept a Wiki write.

The storyboard Instrument beat is Compute with **Room to be wrong** already applied. Leave-open still shows Keep on Parenting when the distinction is live and not yet this definition.

## H1 — Working exhibits

Parenting does not want a compounding calculator. It wants two named readings of the same material, switched in place, labeled as an illustration.

Keep this as an exhibit when a source or another passage is inspectable. Name it. Write this way, and the other way. Show one at a time. Switching does not write the article. The caption is “An exhibit, not evidence.” Empty pending is not a kept closed draft. Identical readings are not live.

Noeis does not generate the readings, claim evidence, or attach a formula the person did not write.

## H3 — Rehearse with your knowledge

“I need to explain this tomorrow. Let me try first.” Try saying it. The attempt stays theirs. There is no grade, no generated gap question, and no celebrity voice.

If a bound source (or the other passage) does not overlap that attempt, it can sit as “Still beside this explanation.” A source set aside for Library limits does not reappear there. Empty pending is not a kept closed draft. Clearing the attempt unmakes it.

## H5 — Discover the unwritten work

Ask what this collection could become that no one source contains. Optionally name what still stops it. Do not auto-fill from Leave-this-open. That question stays H2.

Live when the organizing question is non-empty. Clearing it unmakes the work. The gap may stay empty. The caption is “Unwritten work, not the article.” Noeis does not ghostwrite a thesis.

Library may keep all three. It still cannot propose or accept a Wiki write.

## Taste pass

**Named distinction**
- Eligibility: an opened sentence (Wiki pocket or Library passage). The person may name a distinction with or without an unfinished question.
- Quality bar: the person's words. Not a generated fork. Not a task. Then's question is not copied in. Identity `against` is the current accepted line; restore drops the distinction if that line moved on. Restore cannot invent a distinction from Then.
- Silence: empty distinction stays empty; a distinction that repeats the live question is not a second way home; Then's question stays Then's; a leftover `returnNote` is lifted once, then dropped; trailing spaces while typing are kept, and trimmed only when asking whether the distinction is live. No timer, overdue, or paraphrase. Filler is never the answer.

**Dated reply beside Then**
- Eligibility: Then is showing a recorded question on an opened sentence.
- Quality bar: the same distinction field, sitting beside that question. Date is the day it was first named. Then's question is kept. Not a generated reply. Not a worldview-change announcement.
- Silence: no Then question → the field stays under Leave this open; empty stays empty; a lifted note without a date stays undated; an invalid date is dropped. Filler is never the answer.

**Bears on this distinction**
- Eligibility: an unfinished question, a live named distinction, and a third inspectable recorded passage bound to that claim — not the live source, not the live other.
- Quality bar: identity only. The exact saved passage. The caption is the reason it bears. Not a generated warrant. Not a resolution. Not Meet. Not Then. Restore takes the live third source; a private draft cannot forge one. A third source alone is not a kept draft.
- Silence: no question, no distinction, no third source, the same passage as source or other, an unavailable source, or fewer than two overlapping content words → nothing. Leave-open without later material stays silent. No timer, overdue badge, or paraphrase. Filler is never the answer.

**Keep this as an instrument**
- Eligibility: an opened sentence with a live named distinction whose text is not already this instrument's definition.
- Quality bar: the person's distinction, snapshotted at keep time. They type the name. Not a generated definition. Not a prompt preset. Identity `against` is the current accepted line. Restore drops the instrument if that line moved on.
- Silence: no distinction → no Keep; empty name is not live and is not a kept draft by itself; already this definition → no second Keep; trailing spaces while naming are kept, and trimmed only when asking whether the instrument is live. Filler is never the answer.

**Apply this instrument**
- Eligibility: a named instrument held on the device, and an opened sentence whose accepted line can take it. The person clicks Apply.
- Quality bar: name and definition stay. `against` becomes this line. The article is unchanged. A different live distinction is not overwritten. Earlier applications retain their version.
- Silence: no held name → no Apply; already applied here → no second Apply; a different live distinction → no Apply; a pending snapshot on this line → no Apply; failed/moved line drops restore. Opening a sentence does not auto-apply. Filler is never the answer.

**Keep this as an exhibit**
- Eligibility: an opened sentence with an inspectable source or another inspectable passage, and no pending exhibit on this line.
- Quality bar: two readings the person writes. A name is optional. Switching the shown way does not write the article. Caption: an exhibit, not evidence. Identity `against` is the current accepted line.
- Silence: no inspectable source or other → no Keep; identical or empty readings are not live and are not a kept draft; a moved line drops restore. No generated readings, formulas, or evidence claim. Filler is never the answer.

**Try saying it**
- Eligibility: an opened sentence with no pending rehearsal on this line.
- Quality bar: their attempt. No grade. A source or other sits beside it only when it does not overlap the attempt, and only when that source is not set aside.
- Silence: empty attempt is not live and is not a kept draft; clearing the attempt unmakes it; overlapping source stays quiet; a moved line drops restore. No generated gap question. Filler is never the answer.

**Keep this as unwritten work**
- Eligibility: an opened sentence with no pending unwritten work on this line.
- Quality bar: an organizing question they type. An optional gap. Not copied from Leave-this-open. Not the article.
- Silence: empty question is not live and is not a kept draft; clearing the question unmakes it; a moved line drops restore. No ghostwritten thesis. Filler is never the answer.
