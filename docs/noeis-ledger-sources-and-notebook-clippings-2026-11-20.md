# A way back from finished work and saved reading

- In Work, complete a task captured from a note. Open **Done this week**, tab to the source link, and check that it opens the original passage or dated entry. A linked note without a captured passage opens at the note. An unavailable source leaves the row quiet, and Reopen remains a separate action.
- In Editions, select words from one finding and activate **Keep in Notebook**. Wait for the receipt, then use **Open note**. Check the exact text in an editable quote and the issue link above it. Reload the note and follow the issue link back to the original finding.
- Simulate a save failure. Check that focus stays on Keep, the error is visible, and another attempt works. Submit the same clipping twice concurrently, then retry after editing the note. Verify one saved note and preserved edits. A different selection or account gets its own note.
- Check touch and keyboard at 430px with 125% text, WebKit at 1320px, and Chromium at 1440px.
