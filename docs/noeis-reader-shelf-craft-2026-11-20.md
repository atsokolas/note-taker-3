# Reader, Notebook, shelves, and Judgment

The Reader’s source-specific Back action stays on one line and takes its space before the reading status. In narrow space the status can shorten or disappear. The Back and Partner controls keep separate 44px tap areas.

Notebook’s More menu now owns Hand off. Opening the preview keeps the title and next sentence in place. Escape returns to Hand off, and a second Escape returns to More. The shortcut opens the existing preview with the selected passage. The form still requires explicit submission.

The Library shelf gives the delayed continuation or annotation one reserved line. Books puts the last marked page from the current reading in its own metadata column. Counts and page ranges still describe the book’s marks, and the position stays quiet for an unmarked or finished book.

The Judgment record uses tabular dates. Entries on the same local day show their saved times when available. The source passage aligns with the wording it supports.

## Regression scenarios

- Follow a citation from Editions or Judgment and check that focus reaches the quotation. On a 430px viewport, check Back and Partner at normal and increased text size. Return with Enter and verify focus on the original action.
- Open Notebook’s More with the keyboard, then Hand off. Check the note title, excerpt, and unchanged placement of the saved sentence. Cancel with Escape, reopen via the shortcut on a selected phrase, and cancel again. Confirm that cancellation makes no handoff request.
- Delay the Library trace response until the first two shelf rows are visible. Release it while the first title has focus and compare the second row’s position. Check a Books shelf with a latest mark on an earlier page and enter the book from its row with the keyboard.
- Open a Judgment with two saved times on one date. Confirm both times appear beside the correct record entries, and that the evidence starts at the same edge as the amended words.
